# 诊断报告格式（pdx-map-editor.diagnostic/2）

> 2026-10-17 起，编辑器导出的不再是"一段随手记的日志"，而是一份**可归档、可自动解析**的诊断报告。
> 目标：玩家点一下就能把现场带走；作者拿到报告能直接回答"哪一版 / 什么机器 / 哪张图 / 哪一步 / 出了什么错"。

---

## 1. 从哪里导出

| 入口 | 什么时候能用 |
|---|---|
| **启动页右下角「导出诊断报告」** | 一打开就能点；**编辑器还没起来 / 起不来时也能用**（按钮由 `log.js` 自己绑定，不依赖 `app.js`） |
| 崩溃红条里的「导出诊断报告」 | 出现未捕获异常 / 渲染器失败时 |
| 顶栏「文件 ▾ → 导出日志」 | 编辑器正常运行后 |

文件名：

```
ck3_诊断报告_20261017_134501.txt          # 选了地图：带游戏前缀
pdx-map-editor_诊断报告_20261017_134501.txt # 启动页 / 还没选图
```

编码：**UTF-8 + BOM**，换行 **CRLF**（Windows 记事本直接打开不乱码、不挤成一行）。

## 3. 字段约定

### 顶部

| 字段 | 说明 |
|---|---|
| 报告编号 | `PDX-<YYYYMMDD>-<HHMMSS>-<4 位十六进制>`；同一次页面会话内固定，刷新会换新号 |
| 版本戳 | 构建时写入 `<meta name="pdx-build">` 的打包时间（如 `2026-10-17 13:49`）；开发版显示「开发版」。**不是** `document.lastModified` ✓ |
| 生成时间 | 本机时间 + 时区偏移（`UTC+08:00`） |
| 报告格式 | `pdx-map-editor.diagnostic/2`；字段不兼容时升版本号 |
| 会话时长 | 从 `log.js` 加载到导出的时间 |
| 结论 | `OK` / `WARN` / `ERROR` / `BOOT FAILURE`（启动阶段失败） |

### 错误严重级别

| 级别 | 来源 | 含义 |
|---|---|---|
| `ERROR` | `console.error` / `LOG.error` | 真错误 |
| `WARN` | `console.warn` | 提示，不算故障 |
| `UNCAUGHT` | `window.onerror` | 未捕获异常（最值钱的一类） |
| `REJECTION` | `unhandledrejection` | 没接住的 Promise |

每条错误有稳定编号 `E-001` 起，带 `来源 / 消息 / 位置 / 次数 / 堆栈`；同一处错（忽略数字差异）会合并计次，避免"一秒钟 60 条"把上限占满。

### JSON 附录

`buildRaw()` 生成，字段与正文一一对应：

| 字段 | 类型 | 说明 |
|---|---|---|
| `schema` | string | 固定 `pdx-map-editor.diagnostic/2` |
| `reportId` | string | 同报告头 |
| `generatedAt` | ISO 8601 | UTC 时间 |
| `sessionStartedAt` | ISO 8601 | 会话开始 |
| `durationMs` | number | 会话时长（毫秒） |
| `conclusion` | string | 同报告头 |
| `environment` | object | `[1]` 的键值 |
| `runtime` | object | `[2]` 的键值（含 `渲染器状态` / `渲染器详情` 等） |
| `errors` | array | `{ id, severity, source, time, message, location, stack, count }` |
| `events` | array | `{ id, time, relativeMs, name, detail }` |
| `dropped` | number | 超过上限没留下的记录数 |

> 解析示例（Node）：
> ```js
> const text = fs.readFileSync('ck3_诊断报告_xxx.txt', 'utf8');
> const json = JSON.parse(text.slice(text.indexOf('---- BEGIN JSON ----') + 20,
>                                    text.indexOf('---- END JSON ----')));
> console.log(json.reportId, json.conclusion, json.errors.length);
> ```

## 4. 隐私与边界

- **不包含**涂色图片、地图数据、游戏文件、localStorage 内容。
- **包含**浏览器 UA、页面 URL、显卡型号 / GL 版本、操作时间线 —— 这些是定位问题必需的；发之前如果不放心，可以把 `页面地址` 里的本地路径删掉再发。
- 报告由 `log.js` 在**编辑器还没起来**时也能生成；启动页按钮就是为此存在的。
- 上限：错误最多 200 条、事件 400 条、单条消息 1200 字；超出的只累计 `dropped`，不会把标签页撑死。
