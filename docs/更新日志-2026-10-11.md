## CK3 的 1066 剧本地图

- 数据源：`history/titles` 里 **1066.9.15** 那天的 `holder`（谁占着）和 `liege`（谁是封臣）
- 显示的是**非封臣的那一层**：一路顺着 `liege` 往上，顶到头的那个头衔就是这块地的政权
- **法理（`landed_titles` 那套嵌套 + `de_jure_liege`）不参与实控** —— 它是编辑器里"帝国 / 王国 / 公爵领 / 伯爵领 / 男爵领"那五级，是**另一张图**
  - 我先后两次拿法理去补：一次"没写 liege 就认法理父级"→ 大辽把整片草原吞了；一次"父级是同一个人才跟"→ 辽东又被并回去。两次都被当场抓到，全撤了
- **没写 `liege` = 独立**（`history/titles` 把封臣关系写全了：4351 条 `liege` / 5136 个有持有者的头衔）
- **男爵领不参与**：CK3 里男爵领没法细分，一块地的主人一律看**伯爵领**

## 实控链上认下这些

- **`h_`（霸权）也是头衔**：`h_china` / `h_india` / `h_roman_empire` … 东亚那 885 条 `liege = h_*` 以前整批丢掉 → 东亚碎成一片
- **同一个人的头衔算一个政权**，国号挑法四级：
  1. 层级最粗（h → e → k → d → c → b）
  2. **拿着那个头衔首都的**优先（西夏 `k_xia` 的 `c_lingzhou` 他拿着；`k_hexi` 没写首都）
  3. **不占法理地的**优先（教宗 `k_papal_state` 是无地名誉头衔，`k_romagna` 跟它首都撞车）
  4. 法理地盘最大 → key（结果稳定）
- **obedience / 草原那套**：`nomad_government`（游牧）· `herder_government`（牧民，靠 `uses_county_fertility = yes` 认）· `steppe_admin_government`（草原行政）之间**跨类型不算封臣** → 草原部落独立，辽自己的普通封臣留住
- **朝贡者（`tributary_of`）不是封臣**：全库 262 条（曼陀罗那套为主）自己是一块独立领地
- **换人前的旧 `liege`**：按"**品级不可能**"作废 —— 持有者手里另有一个比封君更粗的头衔时那条不成立（`c_LIAO_yinzhou` 的持有者是渤海**国王**，却被写成辽东**公爵**的封臣 → 作废）
  - 一开始按**日期**一刀切，把西夏那些封臣也误删了，是错的
- **解析要递归**：`history/titles/ce3/` 那种子目录里是一整批 DLC 内容（教宗 / 主教座），以前 `glob("*.txt")` 只扫一层，整批没读到 → 科隆大主教"没人持" → 科堡掉成 2 省小政权

## 八套地图结构统一

- CK3 也照搬"**剧本层 + 地区层**"：1066 是剧本（势力），帝国 / 王国 / 公爵领 / 伯爵领 / 男爵领是地区
- 而且**也补了「空白剧本」那一层**（第 1 层）→ 现在 CK3 / EU4 / EU4HD / HOI4 / VIC3 / EU5 一个结构

## 修的坑

- **剧本模式下涂一块荒地，整片荒地一起上色**：`paintTargetsAt` 是按**归属名字**匹配的，而 CK3 里海 / 湖 / 荒地都是"一个伪头衔管一大片"→ 点一块全片变色。改成**荒地按地块**涂（点中地块自己的最细头衔是荒地 → 只涂这一块）
