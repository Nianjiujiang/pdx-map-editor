## 二、水域重构：最终形态

**用户定的架构（原话）**：

> "你就不能把水域变成一个**仅仅是不能填色的地块**吗，明明在游戏里也是这样的，

> "哇，和陆地一样啊，**大名，河北，华北**，这样下来"
> "是的，只是水域**带一个小标签**来让他在**边界和颜色**等方面听从相关的开关，其他逻辑不变"

**落地结果**：

| | 陆地 | 水域 |
|---|---|---|
| **身份** | 它那一层的头衔 | **它自己**（`#<pid>` / 每层一片 ✓）|
| **特殊之处** | —— | **`meta.waterMask`（每地块 1 字节）** ✓ |
| **颜色** | 头衔色 | **设置里那个统一色**（海/湖/河/不可通行海域各自 ✓）|
| **边界** | 听陆地那几组开关 | 海岸线听 `_anyBorderOn` ✓ 内部听 `uShowWaterIn` ✓ |
| **高亮 / 名字 / 层级** | 普通那套 | **同一套**（不特判 ✓）|

**三个游戏族的差别（用户点破的）**：

| | 逻辑 |
|---|---|
| **CK3 / VIC3** | 游戏里**没有**水域层级 → 每层用同一张表 → 各层片名一样 ✓ |
| **EU4 / EU5** | **每个层面都有海域** → 各层各自的片 ✓ |
| **HOI4** | **state 和 province 共用** → `st` 层拿不到名字就**用地块号**（逐块 ✓）|

**一处改完全部生效**：`build_tier_pieces.tier_pieces()` 里"取不到名字 → 用 `#<pid>`"✓

## 三、三个"层"的分工（别再混 ✗）

这一轮拆出来的，**边界按哪个层**算反复出问题，最后定死：

| 函数 | 管什么 | 没粒度时 |
|---|---|---|
| **`editTier()`** | **动手那一层** —— 边界 / 笔刷 / 涂色 | **视图层** ✓ |
| **`labelTier()`** | **显示那一层** —— 海名标 / 水域内部边界（`uWaterInTier` ✓）| **最低层** ✓ |
| **`viewTierFor(pid)`** | **按这一格挑** —— 高亮 / 悬停卡片 | 有主→视图层 · 无主→最低层 ✓ |

**用户给的规则（原话）**：

> "边界关掉的时候海洋没有内部边界，开启的时候**按粒度上边界**，
> **没有剧本按视图**，**剧本没粒度按最低**"

→ `labelTier()` 正好就是这三条 ✓

**另一句（关键澄清）**：

> "我这里所谓的这些东西都针对的是**在剧本时没有归属具体国家或涂色的东西**"

→ 所以"没粒度就是最低"**只给无主的东西**（水域 / 荒地 ✓），不是所有人的规矩 ✗
   —— 有主的地该按**视图层**（剧本模式 = 国家 ✓ 高亮整国 ✓）

| | 顺序 |
|---|---|

    只改处理器会被同步覆盖回去 ✓ 这一轮补上了 ✓
- `web/index.html` 里那两个 `<label>` **删掉**（不是藏 ✓）

## 五、自动上色"没法上色"：根因 + 修法

**用户报的**：

> "我现在的问题就是**自动上色没法上色**，而不是你所说的特殊情况看起来像没有上色"
> "你算出来有上色，而我这边看不到，你就应该知道问题**不是上色多不多，
> 而是处理好的上色没被我看见**"

**量出来的事实**：

```
自动上色写的是   titleAt(pid, 最细层) = wl_<pid>    ← 颜色算在这儿
显示读的是       titleAt(pid, 当前视图层)           ← 完全是另一个节点
  · 剧本层：荒地无主 → 读到 NONE 那一格 ✗
  · 粗地理层：读到 #wasteland_rg_*（跟邻居共用那片，颜色是类别灰）✗
→ 算好的颜色一次都没被显示过 ✓
```

**修法**：着色器加 `uFineTier`（最细层层号）+ `wasteColourOf(pid)`，
**荒地一律去最细层那个节点取色** ✓

**实测（EU4，停在剧本层）**：87 / 87 块荒地都能取到颜色 ✓

```
pid1779 剧本层tid=65535 → 取到 67,173,153
pid1781 剧本层tid=65535 → 取到 81,114,213
```

⚠ 途中踩的坑：`setFineTier` 第一版加在 `applyEditTier()` 里 ✗ ——
  它**只在换层 / 换粒度时跑** ✓ 载图那一下不一定调到 ✓
  实跑量到 `renderer.fineTier` 还是 0（该是 6）→ 挪到**载图处** ✓

## 七、教训

1. **删 DOM 一律逐行精确匹配** ✗ —— 不要用 `.` 能跨行的正则 ✓
   （一个 `re.S` 就啃掉了整个顶栏 + 面板结构 ✓）
2. **删元素必须同时给"读它的地方"加 null 保护** ✗
   （`$('...')` 返回 null → 崩 ✓）
3. **同一件事有两处赋值时，两处都要改** ✗
   （`setShowWasteColor` 在勾的处理器 + 每帧同步里各一处 ✓ 只改一处会被覆盖 ✓）
4. **"加在哪个函数里"要看那个函数什么时候跑** ✗
   （`setFineTier` 加进 `applyEditTier` → 载图时不跑 → 整个失效 ✓）
5. **模板字符串里的注释不许出现反引号** ✗
   （`gl.js` / `browser_stub.js` 各撕了一次 ✓ 整个文件 SyntaxError ✓）
6. **自检绿 ≠ 对** ✗ —— `browser_stub` 用的是**假 GL** ✓
   GLSL 编译错误它抓不到 ✓（黑屏那类只能靠真机 ✓）
7. **先量再说** ✗ —— 这一轮靠"实跑量一遍"抓到过至少 5 次误判 ✓
   （`NO_TITLE` 判据、候选池、`fineTier`、`showTitles`、自动上色票源 ✓）
