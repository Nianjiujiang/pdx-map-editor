# v1.9

**发布日期** 2026-10-12 · **变更范围** 2026-10-11 – 2026-10-12

这一版两个主线：**导入式地图**（别人做好的图能直接导进来用，不用等作者出「适配某某 mod」的版本），
以及**地图改成单独下** —— 编辑器本体从 35 MB 瘦到 0.6 MB，地图按需下 ✓
完整设计见 [导入式地图-策划](导入式地图-策划.md)。

## Added

- **导入地图包**：选图界面新增「＋ 导入地图包…」，选一个 `.pdxmap` 就能用，
  也可以把文件直接拖进选图界面
- **导入的图存在浏览器里**：刷新、关掉再开都还在，只有手动删才没
- **导入只增不改**：同一个包导两次就是两张图（各自独立，涂色互不影响）；
  作者出了新版本，导进来就是"多一张"，之前那些**一张都不会被动**。
  一模一样的那一份**也照导**（不再弹窗问，多出来的那份卡片左上角有小序号 1 / 2 …）
- **导出**：已导入的图可以再导出成 `.pdxmap`（浏览器存储不是网盘，重要文件自己留一份）
- **删除已导入的图**：卡片右下角「删除」，问一句「是否删除该地图？」就把它连**涂色**一起清掉
  （设置 / 最近颜色按游戏类型存，不归某一张图，删图不动它们 ✓）
- **打包脚本** `pack_map.py`：给地图作者用，把一份 `data_xxx/` 打成 `.pdxmap`
  （打包时会清掉 `meta.json` 里的本机路径，不会把作者的用户名带出去）
- **地图包发布脚本** `build_packs.py`：一条命令把游戏自带那几张图打成 `packs/` 里的 7 个包
- **"还没有地图"的引导**：编辑器本体不再内嵌地图，第一次打开列表是空的，
  那一页会写清楚"地图包是单独下的、要用哪张下哪张"

## Changed

- **编辑器本体不再内嵌地图**（2026-10-12）：`pdx-map-editor.html` 从 **35 MB** 变成
  **0.6 MB** ✓ 游戏自带的地图（CK3 / EU4 / HOI4 / V3 / EU5）也走"导入地图包"这条路 ——
  玩家要用哪张下哪张（0.8–12.3 MB），不用人人下 35 MB ✓
  包跟编辑器一起放在 [Releases](../../releases) 附件里。
  （要"一个文件全都有"的版本也行：`python build_standalone.py --all-maps` 自己烘 ✓）
- 选图卡片改成纯节点拼装（导入的图名字来自陌生人，一律当文字显示，不当 HTML 解析）
- 只有一张图时不再自动跳过选图界面（不然「导入」那个入口就没地方进）
- **删掉了左栏「显示」里那组「头衔」开关**（颜色 / 边界 / 名称 / 父级边界）——
  它是"CK3 特立独行那会儿"留下的：CK3 后来也有了剧本层，
  于是这组在**每一个模式**里都是藏着的（纯死 UI ✗）。
  它管的三样（原版颜色、原版地名、原版边界）现在都由「势力 / 地区」那两组算 ✓
  所以画面**一点变化都没有**，只是少了一排看不见的开关

## 修了

- **着色器链接失败**（v1.8 起就有的）：某些浏览器 / 显卡上打开编辑器直接报
  「着色器链接失败」—— 着色器里一个 `}` 的位置不对，同一个函数里同名变量声明了两遍，
  ANGLE 转 HLSL 之后就是重复定义 ✗ 现在能正常起来了 ✓
  链接失败时也会把驱动给的日志**原样**打出来，不再只说一句"失败了"
- **HOI4 的国名**：`TAG` 优先于 `TAG_DEF` —— TNO 那张图上德国那块以前显示成
  「德意志民族的大日耳曼国」，现在跟游戏里一致（大日耳曼国 ✓）
- **cosmetic 标签按作用域解析**：TNO 把 `NOR = { set_cosmetic_tag = NOR_GER }` 写在
  德国那个文件里，以前按"文件里的国家"归属，于是**德国那一块变成了挪威专员辖区** ✗
  现在按它写在谁的作用域里认 ✓（13 个映射跟着修正）
- 一进编辑器就浮着一个"导入窗口"，而且关不掉（那个「⋯」管理面板的 `display: flex`
  把 `hidden` 属性压过去了；现在样式表里有全局兜底 `[hidden] { display: none !important }`）
- 轻量版里 `window.__CK3_EMBEDDED__={maps:{}}` 被当成"有内嵌数据"，
  读字节时会去解一份空数据（报 `atob` 的错）✗ 现在空的就是空的

## 2026-10-12 这一轮（发布前又收拾的）

- **导入可以一次选好几个** `.pdxmap`（直接拖好几个文件进来也行）：挨个导，
  一个读不了不影响后面的
- **卡片上直接长着「导出」「删除」两个动作** —— 原来藏在右上角那个「⋯」小面板里，
  多一次点击才看得见；面板连元素带样式整个拆了
- **卡一多就排两列**（默认 10 张起）：列表排两列、面板跟着放宽、列表自己滚
- **设置 / 最近颜色改成按「游戏类型」存**（以前按每张图）：同一个游戏的不同图
  **共用一套**（TNO 和钢铁雄心4原版是同一份 ✓），换张图不用重调；
  **删掉某一张图也不会把它们带走** ✓
  （涂色暂存照旧按"哪一张图"分 —— 那个共用会把两张图互相涂花 ✗）
- 卡片上不再写「已导入」三个字（右下角那两个按钮本身就是标记），
  只留版本号；同一个包导了不止一份时左上角标个小序号
- 文案收拾：「导出备份」→「导出」；三条提示统一成
  「成功导入地图：名字」「成功导出地图：名字」「成功删除地图：名字」；
  「还没有地图」那句引导挪进下面那个提示框里（省一块地方）
- 手机版滚动条统一染成暗色（以前没被管到的地方会露出浏览器那根白条 ✗）

## Notes

- 地图包必须属于现有五个游戏之一（CK3 / EU4 / HOI4 / Victoria 3 / EU5），
  术语、图层、导出格式全部沿用那个游戏现成的设定
- 包在导入前会整个校验一遍：格式、清单、哈希、长度公式、省份号范围、分块尺寸；
  不合规的包**一个字节都不会存进来**，并且会说清楚是哪个文件、哪儿不对
- 这台浏览器不让存本地数据（或者开了隐私模式）时，导入的图只在本次会话里有效，
  界面上会明确写出来
- 导入的地图存在**浏览器**里，不在 HTML 文件旁边 —— 换电脑、清浏览器数据都要重新导一次，
  原文件自己留好（编辑器里每张图也有「导出」）
