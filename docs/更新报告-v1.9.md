## 一、先说结论：这版最值得看的五件事

1. **编辑器和地图分家**：`pdx-map-editor.html` 从 **35 MB** 瘦到 **0.85 MB**，
   地图变成 8 个 `.pdxmap` 包，要用哪张下哪张。
2. **新增 CK2**：四级头衔、1066.9.15 剧本、汉化、水名/荒地真名，全部接进同一套编辑器。
3. **导入式地图**：别人做的 mod 图也能打成包导进来；导入的图存在浏览器里，
   刷新还在，能导出、能删除；自带 8 个原版/变体包。
4. **水域 / 荒地 / 名字规则重做**：水不能涂、荒地可涂且能自动上色；
   名字按游戏和地块类型决定显不显示；悬停卡片按每个游戏的规格表来。
5. **稳定性**：修掉"WebGL 上下文丢失被误报成着色器编译失败"这个关键误诊；
   启动页和崩溃页都能一键导出正式诊断报告；一轮体检把认族/重绘/启动都提了速。

## 二、地图：从"一个 35 MB 的大文件"到"编辑器 + 8 个包"

### 2.1 体积

| 文件 | 大小 | 说明 |
|---|---:|---|
| `pdx-map-editor.html` | **0.85 MB** | 只有代码，不含地图 |
| `pdx-map-editor-mobile.html` | **0.95 MB** | 手机版，单独发布 |
| 8 个地图包 | 0.41 – 12.50 MB | 按需下载，见下表 |

以前所有人下 35 MB；现在只要下编辑器 + 自己要看的那张图。

### 2.2 随版本发布的 8 个包

| 包 | 地图 | 大小 |
|---|---|---:|
| `pdx-ck3-vanilla.pdxmap` | CK3 原版 | 2.43 MB |
| `pdx-ck2-vanilla.pdxmap` | CK2 原版 | 0.41 MB |
| `pdx-eu4-vanilla.pdxmap` | EU4 原版 | 0.82 MB |
| `pdx-hoi4-vanilla.pdxmap` | HOI4 原版 | 1.52 MB |
| `pdx-hoi4-alt.pdxmap` | HOI4 修改边界 | 1.49 MB |
| `pdx-vic3-vanilla.pdxmap` | VIC3 原版 | 3.67 MB |
| `pdx-eu5-vanilla.pdxmap` | EU5 原版 | 4.17 MB |
| `pdx-eu5-full.pdxmap` | EU5 原尺寸 | 12.50 MB |

包由 `build_packs.py` 一条命令重打；全部是游戏自带地图，创意工坊 mod 地图没有授权，不随编辑器发布。
想自己把授权过的 mod 打成包，用 `pack_map.py`，格式见
[导入式地图-策划](导入式地图-策划.md)。

### 2.3 导入、保存、导出、删除

- 选图页新增「**＋ 导入地图包…**」，也可以把 `.pdxmap` 直接拖进选图页；
- **支持一次选多个**，一个读不了不影响后面的；
- 导入的图存在**浏览器**里：刷新、关掉再开都还在，只有手动删才没；
- 同一张包导两次 = 两张独立的地图，涂色互不影响；
  一模一样的那份也照导，卡片左上角用小序号 1 / 2 … 区分；
- 每张卡右下角有「**导出**」「**删除**」：
  - 导出 = 把这份图重新打回 `.pdxmap`（浏览器存储不是网盘，重要文件自己留一份）；
  - 删除 = 问一句「是否删除该地图？」，连它的涂色一起清掉；
- 设置 / 最近颜色改成**按游戏类型**存：同一个游戏的几张图共用一套设置，
  删掉某张图也不会把设置带走；涂色暂存仍按"哪一张图"分，避免互相涂花。

### 2.4 包的安全与兼容

- 导入前整包校验：格式、清单、哈希、长度公式、省份号范围、分块尺寸；
  不合规的包**一个字节都不会存进来**，并会说清是哪个文件、哪里不对；
- 包必须属于现有六款游戏之一，术语、图层、导出格式沿用该游戏现成设定；
- 浏览器禁止本地存储时，界面会明确写「刷新就没了」，不会假装存上了。

## 三、新增地图与数据

### 3.1 CK2：新游戏支持

- **1066 剧本**：时间口径取书签 `1066.9.15`，不是随手拍的日期；
- **四级头衔**：帝国 / 王国 / 公爵领 / 伯爵领。
  CK2 的男爵领是伯爵领里的地产，不占地图像素，所以没有第五级；
- **汉化**：自动识别 `ck2_chinese` 的编码（latin1ck2 三字节），
  中文 → 英文 → 键名逐级回退；省份 1740/1740、头衔 2686/2691 命中；
- **水名 / 荒地真名**：CK2 的水和荒地既有自己的名字，也能一块一块涂；
- **湖泊 / 河流判据重做**：不再按 `major_rivers` 名单硬猜。
  真正的河 = 名单 ∩ `adjacencies.csv` 的 `major_river` 穿越点（91 段）；
  连不到大洋的封闭水体 = 湖（36 个）；其余贴地图边缘的水 = 海（132 个）。
  里海、咸海、罗布泊现在都归湖，伏尔加 / 奥卡那串真河段仍是河；
- 数据规模约 2000 个地块、4055 个头衔，包只有 0.41 MB。

### 3.2 EU5：水陆混片、跨接缝名字、原尺寸

- **水陆混片拆分**：EU5 的大区域原来水陆共用一个 tid，涂色/悬停/边界会一起动；
  现在区域、地区、省份三层的水成员各自拆片，名字仍沿用原片真名；
- **跨接缝水名**：太平洋这种横跨左右边界的海，左右各出一个名标，
  中部不再重复出标；
- **一片一标**：有独立片的，一片一个名字；只有老包"整类共用一个共享节点"才按名字合组；
- **EU5 原尺寸**：`pdx-eu5-full` 保留原分辨率，地块更细、开图慢几秒；
  分块图开图时先用邻接表近似，后台再逐块算精确周长。

### 3.3 底层身份标（kindMask）

六款游戏现在都能在数据里标出每个最低单位是什么：

```
1 陆地 · 2 海洋 · 3 湖泊 · 4 河流 · 5 不可通行海域 · 6 不可通行区域
```

它决定水/荒地的颜色和名字该听谁的，不再靠"键名里有没有 sea / lake"去猜。
老包没有这枚标时，编辑器仍会自动退回键名前缀，行为不变。

## 四、界面与操作

### 4.1 选图页

- 地图卡片**统一一列列表**，卡片多了列表自己滚，不再分两列；
- 每张卡显示名字、版本号；导入的图多出「导出 / 删除」和 1 / 2 小序号；
- 一张图都没有时，列表位置会写清"地图包是单独下的、要用哪张下哪张"；
- 手机版把文件选择器的 MIME 过滤放开，`.pdxmap` 不再灰着点不动。

### 4.2 左侧「显示」区

从原来的多组开关收成现在这几块：

- **势力**：颜色 / 边界 / 名称（玩家涂色层；原来叫「填色」，这版改名）；
- **水域**：边界 / 名称；
- **荒地**：边界 / 名称 / 自动上色；
- **清除全部**（有荒地时再加一颗**清除荒地**）。

另外：原「剧本」那一组（颜色 / 边界 / 名称）整组删掉了 —— 它早就是死 UI；
启动页署名拆成两行，右边显示真实打包时间，不会再假装成"当前时间"。

几条规则：

- 水域和荒地的边界 / 名称**各管各的**：把「地块」「势力」全关掉，
  水域和荒地自己的线照样在，想关就关它们自己的勾；
- 水域边界只管**水与水之间**的缝，海岸线仍归地块/势力边界；
- 荒地边界只管**荒地与荒地之间**，挨着陆地/水的外缘不归它；
- 没有荒地设定的游戏（VIC3 / HOI4）**整组隐藏**：
  显示区的荒地组、设置区的荒地滑条、清除荒地按钮都不出现；
- 清除荒地 = 清掉荒地块上的手绘色 + 关掉自动上色 + 刷回荒地灰，
  没有荒地的图按钮直接隐藏。

### 4.3 设置面板

四栏：**颜色 / 边界 / 名字 / 其他**。

- **颜色**：七行实时生效，不用重烤包 ——
  空白区域、无归属区域、不可通行区域、河流、湖泊、海洋、不可通行海域；
- **边界**：五类（省份 / 地区 / 势力 / 水域 / 荒地），每类两行 ——
  边界宽度（0.5–3，步长 0.5）、边界不透明度（0 / 25 / 50 / 75 / 100）。
  0% = 那条线完全不画；没有荒地时荒地那一档不显示；
- **名字**：按对象分「地块」「势力」两块，各有字号倍率（0.5–3，步长 0.1）、不透明度、上限。
  **地块名称上限默认 1**（每个头衔只留面积最大的那个连通域标），
  想多显示可以自己拉高；势力名称上限默认 12；
- 设置按**游戏类型**存，换同游戏的另一张图不用重调；
  老版本"按图存"的设置会迁移一次，不会一夜回到出厂值。

### 4.4 悬停卡片与左侧方块

- 悬停卡片和左侧栏共用同一个 `hoverTileLines()`，不再两边各拼一套；
- **左侧方块的编号始终是"所指地块的最低级号码"**，不是地名；
- 第二行按游戏和类别显示「海洋 / 湖泊 / 河流 / 不可通行区域 / 不可通行海域」等类别名；
- 悬停规格按游戏分开：

| 类别 | CK3 | CK2 / EU4 / EU5 | VIC3 / HOI4 |
|---|---|---|---|
| 荒地 | 第一行「不可通行区域」 | 最低单位真名 | 无此设定 |
| 河流 | 「河流」 | CK2 给真名；EU4/EU5 无此设定 | 无此设定 |
| 湖泊 | 「湖泊」 | 最低单位真名 | 「湖泊」 |
| 海域 | 「海洋」 | CK2 真名；EU4/EU5 按层级 + 最低单位名 | VIC3 最低单位名；HOI4 战略区名 |

- 占位号（`#281` / `#8613` / 纯数字 / 空）**任何一行都不许原样出现**：
  真名表取不到就退类别名，再取不到就留空；
- 悬停和涂色都按**最低单位的那一格**来：海 / 湖 / 河 / 荒地不会再"整类一起亮"；
  水域直接禁止涂色，荒地可以单独涂；
- 地名恢复**横平竖直**，不再倾斜 / 变形。

### 4.5 涂色与取色

- **水域不能涂**：河流 / 海洋 / 不可通行海域 / 湖泊，鼠标是禁止光标，点了不动；
- **荒地可以涂**：荒地是普通地块，涂过色就按你的颜色显示；
- 右键取色：
  - CK3 的水 / 荒地：不给予具体 `#编号` 标记；
  - HOI4 的 prov / state 水域：给所属**战略区名**；
  - 除 EU4 / EU5 / CK2 外的湖泊：不给标记；
  - 其余水：真名表 → 类别名。

## 五、名字、水域、荒地的最终规则

### 5.1 地图上画不画名字

不是"所有名字都画"，而是按游戏 + 类别决定：

| 类别 | 显示规则 |
|---|---|
| 陆地 | 全部显示 |
| 海域 | CK2 / EU4 / EU5 / VIC3 显示；CK3 不显示；HOI4 只显示战略区，state / province 不显示 |
| 湖泊 | EU4 / EU5 / CK2 显示，其他不显示 |
| 河流 | CK2 显示，CK3 不显示，其他无此设定 |
| 荒地 | CK3 不显示；EU4 / EU5 / CK2 显示；VIC3 / HOI4 无此设定 |

### 5.2 一片一标

- 有独立片的，一片一个名字；
- 只有老包那种"整类共用一个共享节点"才按名字合组；
- 类名 / 占位号 / 空名字不画；
- 跨左右接缝的水域左右各一个标，中部不重复；
- 水名、荒地名、普通地名共用同一个缩放门槛，不会"这块出来了那块没出来"。

### 5.3 水域

- 水域 = **不能填色的普通地块 + 一个小标签**：
  有自己的 pid，参与悬停 / 层级 / 名字，只是颜色听设置、边界听水域开关；
- 颜色一律用设置里对应那一档；
- 内部边界独立一条通道，不受地块/势力边界开关牵连；
- 海岸线照旧归地块/势力边界。

### 5.4 荒地

- 默认是「不可通行区域」的灰；
- 打开「荒地 · 自动上色」后，按周围陆地最低地块的颜色按共享边长加权，
  某种颜色**严格过半**才给它；周围是荒地会一圈一圈往里传染；
- 没有过半 / 没有可用颜色 → 回退荒地灰；
- 默认关闭，想要自己勾；剧本视图里不再检查地区颜色；
- 「清除荒地」会清掉手绘色并关掉自动上色，避免清完下一帧又刷回来；
- VIC3 / HOI4 没有荒地设定，相关 UI 全部隐藏。

## 六、稳定性、性能与诊断

### 6.1 "打开就报着色器编译失败"的误诊

这是 v1.9 周期里最关键的一个修复。

- 以前：`new MapRenderer()` 抛出的**任何**异常都会被写成「着色器编译失败」；
- 真实原因常常是 **WebGL 上下文丢失 / 超时**，驱动或浏览器把上下文收走了，
  编译查询自然失败，于是被误报成着色器写错；
- 现在：新增 `RendererSetupError`，按阶段分成
  `no-webgl2` / `context-lost` / `out-of-memory` / `shader-compile` / `shader-link` /
  `texture-limit` / `renderer`；
- 编译前后都检查 `isContextLost()` 和 `glError`；上下文丢失不再怪着色器；
- `context-lost` / `out-of-memory` 自动重试最多 2 次；
  真着色器错误不重试，直接把驱动日志原样打出来；
- WebGL 恢复时走 `webglcontextrestored` 重建，不重新 `new MapRenderer`。

### 6.2 诊断报告

- 启动页、崩溃红条、顶栏「文件 ▾」三处都能导出；
- **启动页按钮由 `log.js` 自己绑定**，编辑器没起来也能导；
- 报告六节：环境信息 / 运行状态 / 错误摘要 / 错误明细 / 事件时间线 / JSON 附录；
- 每条错误有 `E-001` 编号、严重级别、位置、栈、次数；
- 时间线 `T-001` 起，带相对毫秒；
- JSON 附录可以直接喂给分析脚本；
- 报告里写构建时间，不再拿 `document.lastModified` 当版本戳；
- 不包含涂色图片、地图数据、游戏文件或浏览器存储内容。

字段和隐私边界见 [诊断报告格式](诊断报告格式-2026-10-17.md)。

### 6.3 性能

一轮体检 + 结构改造后的数字（VIC3 40,876 地块，同机两轮）：

| 项目 | 旧 | 新 | 变化 |
|---|---:|---:|---|
| `playerGroupPidsAt` | 8.23 ms | **0.72 ms** | 约 11 倍 |
| `playerGroupTidsAt` | 6.90 ms | **0.74 ms** | 约 9 倍 |
| 涂色后重分组（细分层） | — | — | **-14%** |
| 涂色后重分组（全图模式） | — | — | **-6%** |

另外：15 处设置取值收进 `setNum()`，12 处"推渲染器"的手写复制收进 `pushRenderer()`；
启动时一处 O(组数 × 地块数) 的白扫改成 O(地块数)。

### 6.4 手机版

- 启动页、设置页、显示区按手机屏幕重排；
- 滚动条统一暗色，不再露浏览器白条；
- 设置页高度自适应，四栏不会挤成一条；
- 文件选择放开 MIME 限制，`.pdxmap` 能正常选；
- 地图列表单列滚动，不强行分两列。

## 七、值得单独说的修复

- **着色器链接失败**（v1.8 遗留）：着色器里一个 `}` 提前关闭了代码块，
  ANGLE 转 HLSL 后出现重复定义；已修，失败时输出驱动原文；
- **HOI4 国名**：`TAG` 优先于 `TAG_DEF`，不再把「大日耳曼国」写成超长名；
- **cosmetic 标签作用域**：TNO 把 `NOR = { set_cosmetic_tag = NOR_GER }` 写在德国文件里，
  以前按文件归属，德国会变成挪威专员辖区；现在按作用域认，13 个映射修正；
- **一进编辑器就浮着导入面板**：`display: flex` 压过了 `hidden`，已加全局 `[hidden]` 兜底；
- **轻量版空数据报 `atob`**：`__CK3_EMBEDDED__={maps:{}}` 被当成"有内嵌数据"，已修；
- **产物里残留 `<script src="js/log.js">`**：单文件版去抓不存在的文件，

## 八、升级须知

1. **v1.9 的编辑器本体不带地图**。先下 `pdx-map-editor.html`，再去附件下要用的
   `.pdxmap`，在选图页导入。想要"一个文件全都有"，用
   `python build_standalone.py --all-maps` 自己烘全量版。
2. **导入的图存在浏览器里**，不在 HTML 旁边。换电脑、清浏览器数据都要重导；
   重要涂色请用「导出涂色」，地图本身用卡片上的「导出」留一份。
3. **设置改成按游戏存**。老版本按图存的设置会自动迁移一次；
   如果升级后发现某项设置没接上，去设置页确认一下即可。
4. **地块名称上限默认改成 1**。觉得名字少，可以在设置 → 名字 → 地块 → 上限里拉高（1–21）。
5. **水域不能涂**，荒地可以涂。想把荒地当普通地块用，直接涂即可；
   「清除荒地」会把荒地手绘色清掉并关掉自动上色。
6. **EU5 原尺寸**地块更细、开图慢几秒；普通 EU5 包更轻快。
7. **EU4 高清**是创意工坊 mod 地图，没有授权，不随编辑器发布；
   本地有缓存的话可以用 `pack_map.py` 自己打包导入。
8. **报告里的本机路径**：诊断报告会记录页面 URL 和浏览器信息，
   发到公开场合前可以自己看一眼，介意的话把路径删掉再发。
