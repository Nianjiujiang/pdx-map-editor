## 四、三个真 bug（值得记）

**① 着色器链接失败（v1.8 起就有的）** —— 某些浏览器 / 显卡上打开编辑器直接红字「着色器链接失败」✗

病因：着色器里一个 `}` 的位置不对，把 `if (pidAt(ip) != 0u)` 那个块**提前关掉了** ✗
→ 同一个函数里同名变量（`R` / `dTitle` / `dPaint` / …）声明了两遍
→ ANGLE 转成 HLSL 之后就是重复定义 ✓

（假 DOM 不做 GL，自测**永远逮不到**这一类 ✗ 只能靠静态读 + 廿九在真浏览器上点 ✓
 顺带：真失败时把**驱动给的日志原样**打出来，不再只说一句"失败了" ✓）

**② TNO 图上德国那块显示成「挪威专员辖区」** —— TNO 把
`NOR = { set_cosmetic_tag = NOR_GER }` 写在**德国那个文件**里 ✗
旧的 `parse_cosmetic_tags` 按"文件里的国家"归属 → 德国就拿到了挪威的 cosmetic ✓
改成**按作用域**认（`_collect_cosmetics` 递归 + 排除 `IF/ELSE/AND/OR/NOT/ROOT/PREV` 这些键）✓
13 个映射跟着修正 ✓ 原版那套映射**逐项验过没变** ✓

**③ 手机上选不了 `.pdxmap`** —— `.pdxmap` 是自定义扩展名，系统报给选择器的类型是
`application/octet-stream` ✗ 而安卓 / iOS 的文件选择器**按 MIME 过滤** ✗ → 文件灰着点不动 ✓
两道修法：源头 `accept` 里补 `application/octet-stream` ✓ + 手机版 `bindMobile` 里
直接 `accept = '*/*'` 放开过滤 ✓（选错了也进不来，`pack.js` 的校验器会说清楚哪个文件哪儿不对 ✓）

**④ 顺带**：HOI4 国名 `TAG` 要优先于 `TAG_DEF` ✗（不然会冒出「德意志民族的大日耳曼国」这种长名字 ✓）

## 七、教训（都是自测逮不到、或者自测"帮倒忙"的那种）

1. **按钮的 `onclick` 必须把 Promise 返回出去** ✗ —— 自测走的是 `await 按钮.onclick(...)`，
   不 return 的话它拿到 `undefined` 就往下跑，导出 / 删除还在后台跑 → 6 条断言当场红 ✓
2. **假 DOM 的 `className` 和 `classList` 不同步** ✗ —— 读类名要用 `classList.contains` ✓
3. **假 DOM 里解析出来的节点没有 `parentNode`** ✗ —— 要往上找祖先就给它个 id ✓（`#boot-inner`）
4. **`check_standalone` / `check_mobile` 测的是烤出来的产物** ✗ —— 改完源码不重建就跑，必红 ✓
5. **别把"自己推的"当事实写进发布说明** ✗（附件清单那种 —— 谁传了什么只有廿九知道 ✓）
6. **给"首页那行说明"补注释时，位置要挑** ✗ —— Python 的 `# -*- coding -*-` 和 docstring
   都不能动，所以那 4 个脚本统一加在**文件末尾** ✓ 加完逐个 `py_compile` 验一遍 ✓
