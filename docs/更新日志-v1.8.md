# v1.8

**发布日期** 2026-10-10 · **变更范围** 2026-10-08 ~ 2026-10-10

## Added

- 势力名称上限：按势力独立计算，范围 1–20，最高不限
- 连通域命名：同一势力名下互不连通的区域各自独立命名
- 高清地图导出：输出 2×（面积 400%），边界按目标尺度重绘
- 填色工具：单击式落笔，拖拽不连续填充（对标 mapchart "one"）
- 取色后自动切换工具：吸管 / 右键 / 搜索色块 / 调色板取色后切至涂抹或填色（可配置）
- 水域边界、不可通行区域边界：宽度与不透明度独立可调
- 边界宽度新增 0.5 档位；边界浓度新增 0% 档位
- 名字相关滑条显示当前值

## Changed

- 工具更名：还原 → 橡皮，涂色 → 涂抹
- 设置项更名：每国名字上限 → 势力名称上限；国名不透明度 → 势力名称不透明度
- 顶栏布局调整：教程、署名并入左侧工具栏；导入 / 导出 / 清除合并为「文件」
- 设置面板宽度 980px → 1120px
- 默认边界宽度统一为 1.0
- 地点名与势力名不透明度统一为 50%
- 设置与「最近使用」颜色在刷新后保留

## Fixed

- 地区图层填色后切换至省份图层，工具状态异常
- HOI4 省份 3511 / 4788 / 4343 误判为水域（色差阈值 0.02 → 0.004）
- 已填色的荒地在边界判定中仍按荒地处理
- 搜索结果取色未写入「最近使用」
- 手机版工具选择后设置面板未自动收起
- 手机版地图渲染黑屏，且无任何报错（采样器未绑定纹理）
- 空白剧本下无法取色
- 已填色地块取色返回荒地灰
- 错误提示面板无法关闭

## Performance

- 边界改为加载期预计算：每格 1 bit，约 85% 像素提前返回；缩放时射线按步长跳采样
- 边界纹理内存 88MB → 1.4MB
- 图层切换与填色不再重建边界数据
- 拖拽填色不再逐帧重建色块
- 滚轮缩放合并至单帧
- 悬停同势力地块不再整图重绘
- 射线半径上限 48 → 12；水岸线与荒地边界并入填色通道
- 画布像素总量上限，超限降采样
- 缩放性能优化
