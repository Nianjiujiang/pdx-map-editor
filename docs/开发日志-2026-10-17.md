## 一、荒地上色：推翻重做 ★

### 1.1 用户口径（原话整理）

> 检查每个荒地周边的所有陆地最低地块（如 EU4 是 province）。
>
> 若为 1444 等视图（无论有无粒度）：
> - 若有玩家涂色，则该 province 被视作玩家涂色；
> - 否则，若剧本有归属，则该视作当前剧本的颜色；
> - 否则，若地区颜色开关打开，则该视作目前粒度上该 province 所属头衔的颜色。
>
> 若没有 1444 等视图：
> - 若有玩家涂色，则该 province 被视作玩家涂色；
> - 否则，若地区颜色开关打开，则该视作目前视图上该 province 所属头衔的颜色。
>
> 所有 province 检查一遍之后，该荒地若未被上色，则边长中占比 50% 以上的颜色会被赋予给此荒地。

⚠ **上面「剧本视图里还可能看地区色」那条最后被改了** ✗ ——
用户收尾时追加："剧本模式开启时的荒地上色不再检查地区颜色" ✓ 见 1.4。
现在剧本视图只认 **玩家涂色 → 当前剧本色 → 其他荒地的传染色**。

举例（用户给的）：

- EU4 1444 的塔克拉玛干：玩家涂得多 → 玩家色；否则 → 叶尔羌色；
  没有剧本归属但地区色开着、周围五颜六色无法过半 → 回退设置里的荒地色；
  三个颜色全关 → 荒地色。
- CK3 帝国级视图：玩家涂了吐蕃帝国 → 那些山地变成玩家色；
  没涂色且地区色开着 → 吐蕃帝国的红色。

### 1.2 用户随后拍板的四个细节

| 问题 | 用户选择 |
|---|---|
| 剧本视图、无粒度时「地区色」看哪层 | ~~当前视图层~~ → **最后改成：剧本模式完全不看地区色**（1.4） |
| 50% 的分母 / 荒地邻接荒地 | **全部陆地周长**；其他荒地也投票并**逐圈传染** |
| 要不要开关 | **加一个「荒地自动上色」开关** |
| 玩家直接涂过的荒地 | **继续算自动色**；显示以玩家涂色为准 |

追加：**自动上色默认关闭**（用户 2026-10-17 定）。想要上色自己勾。

### 1.3 实现

- **判定单位 = 每块荒地自己的 pid**，颜色写在它最细层的 `wl_<pid>` 节点 LUT 上。
  - 粗层荒地块是同名几块共用的（`#impassable_c_3` 那种），写上去会互相踩 ✗。
- **着色器按 `uFineTier` 读最细层**，跟当前视图 / 粒度无关。
  - LUT 的 **alpha = 255** 当"这是荒地"的标记（那个通道别处没用过）。
- **周长表 = `pid → [[邻居 pid, 共享边像素数], …]`**，水边不算。
  - 有整张省份 id 图 → 开图时直接扫（CK3 42M 像素实测 **0.08s**）。
  - EU5 原尺寸那种分块图 → 先用邻接表给近似，开图后**后台逐块算精确值**再替换。
- **固定点迭代**：每一圈拿上一圈的快照投票，最多 32 圈。
  - 回退灰**只进分母、不投票** —— 否则一大片荒地会互相堵住，颜色传不进去。
- **实时更新**：帧循环里的 `wasteWatch()` 按签名重算
  （层 / 粒度 / 三个颜色 / 开关 / 涂色序号 / 周长表版本 / 设置里的荒地色）。
  - 实测重算耗时：EU4 约 **0.17ms**，EU5 约 **2.9ms**。

### 1.4 最后追加：剧本模式不再检查地区颜色

用户（收尾时）：

> 剧本模式开启时的荒地上色不再检查地区颜色。

- `wasteVoteColor` 里那条地区色分支加了 `!isEra`：
  - **剧本视图**：玩家涂色 → 当前剧本色 → 其他荒地传染色。
  - **非剧本视图**：玩家涂色 → 当前视图上该地块所属头衔的颜色。
- 剧本里没归属的邻居**不拿地区色来凑**，只进 50% 的分母 ✓。
- 粒度不再影响荒地取色；地区色开关在剧本视图里对荒地**完全无效** ✓。
- 自测加了一条：空白剧本 + 粒度开到地理层 + 地区色打开 → 所有荒地必须回灰 ✓。
  - CK3 `0 / 671`、EU4 `0 / 87` 染上地区色 ✓。

### 1.5 验证结果

- EU4 1444 塔克拉玛干 → 叶尔羌色 `[255,245,220]` ✓
- CK3 帝国级视图 → 671 块荒地里 **651 块**拿到颜色 ✓
- 三个颜色全关 → 全部退回 `[94,94,94]` ✓
- 玩家涂色占周长过半 → 荒地取到玩家色 ✓
- 关掉开关 → 全部回退荒地色 ✓

## 二、CK3 荒地上色不显示：`kind = 6` 的顺序坑 ★

### 2.1 症状

用户报：

> CK3 的荒地上色问题有点大，右键取色和鼠标悬停都显示上色成功，
> 可是实际上看上去还是荒地的颜色。

### 2.2 根因

CK3 的荒地底层身份是 **`kind = 6`**（不可通行山地）✗。

着色器 `colorOfPid` 原来的顺序是：

```
手绘层 → kind >= 2 直接返回类色 → 荒地 alpha 分支 → NONE 早退 → 头衔色
```

于是 CK3 的荒地先在 `kind >= 2` 那里拿到了「不可通行区域」的灰，
**根本走不到荒地分支** ✓。

而右键取色 / 悬停卡片走的是 CPU 侧的 `displayedColor` ——
它里面荒地分支排在 `kind` 之前，所以取色和悬停**看起来是对的** ✓。
两边顺序分岔，正是"取色说成功、画面没变"的来源。

### 2.3 修法

把荒地的 `uFineTier` 取色分支**提到 `kind >= 2` 之前**：

```
手绘层 → 荒地 alpha 取色 → kind >= 2 类色 → NONE 早退 → 头衔色
```

水不会误命中：水的 LUT alpha 是 0，查完会继续往下走 `kind` 那条 ✓。

### 2.4 守卫

`test_modes.js` 加了一条**静态顺序断言**：

```
荒地取色 @iWaste 必须 < kind >= 2 @iKind
```

以后再有人把这一段挪回去，自测会直接红 ✓。

## 三、显示区精简

### 3.1 删掉「剧本」整组

用户：

> 把显示区的剧本颜色、边界、名称三个开关去掉，已经没什么用了。

- HTML 里 `power-group` 整组删除：`show-power-border` / `show-power-names` / `show-power-color` 都不在页面上了。
- 内部口径改成固定值：
  - `state.showPowerColor = true` —— **剧本颜色固定开**。
  - `state.showPowerBorder = false` —— **剧本边界固定关**。
  - 剧本名称本来就跟「势力 · 名称」是同一个状态，不需要第二个入口。
- `syncLayerSwitches` / `syncParentBorder` 不再拿 `$('show-power-*')` 当存在性判据。
- 只靠「剧本·边界」才能触发的"按整个国家涂色"那条路一并删除（不再有入口）。

### 3.2 「填色」改名「势力」

用户：

> 把显示区的涂色两个字改成势力。

- 只改**显示标签**：`<span class="group-label">势力</span>`。
- 里面三个 id 一律没动：`show-border-paint` / `show-labels-paint` / `show-paint`。
  - 它们仍然是玩家涂色层的老接口，改 id 会牵一大片 ✓。
- 「势力 · 名称」现在是势力名称唯一入口 ✓。

### 3.3 自测跟着改

假 DOM 的 `getElementById` **找不到会现造一个** ✗ ——
所以"删掉了没"不能靠 `get()` 判，必须扫 `web/index.html` 源码：

- 断言 `power-group` / 三个 `show-power-*` 一个都不剩 ✓
- 断言组名是「势力」、没有「填色」✓
- 删掉过时的"两个名称勾互相镜像"断言 ✓
- 删掉"只开剧本边界 → 按整个国家涂色"的断言 ✓
